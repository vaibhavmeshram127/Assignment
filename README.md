# Assignment
This project replicates the output interface and evaluation layout from the research paper:


Title: Unlocking the Conversion of Web Screenshots into HTML Code with the WebSight Dataset


Authors: Hugo Laurençon, Léo Tronchon, Victor Sanh


Published: 2023

Source: Hugging Face / arXiv


The paper introduces a vision-language model trained to convert webpage screenshots into semantic HTML. My project recreates the visual and structural outputs using HTML and CSS, showcasing how screenshots are interpreted and reconstructed as code.
