Dataset Overview

The WebSight dataset pairs webpage screenshots with their corresponding HTML code. It is designed to train and evaluate models that convert visual web interfaces into structured HTML outputs.

Key Features

  • Thousands of webpage screenshots with matching HTML files
  • Variety of layouts: forms, navigation bars, tables, and content sections
  • Supports research in computer vision and web development
  • Provides benchmark tasks for vision-language models

Example Entry

Each dataset entry includes:

  • Screenshot: PNG image of a webpage
  • HTML Output: The code that renders the screenshot
  • Metadata: Page type, layout category, and complexity level
